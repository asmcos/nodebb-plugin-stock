# nodebb-plugin-stock

在帖子、预览和摘要里识别 A 股代码，显示名称、现价和涨跌幅，并链到 K 线。

写法：`sh600563`、`sz002156`、`bj430047`，代码和数字之间也可以有一个点（`sh.600563`）。

发帖时会在代码后面记下当时的价格，例如 `sh600563[时间:6/17/2026,价格:170.22]`。打开帖子时再拉一次实时行情，历史价格留在「记录」里。

行情接口：`https://api.klang.org.cn/v2/list/`  
K 线：`https://klang.hk.cn/kline.html?code=`

兼容 NodeBB 4。相对旧版修了这些地方：

- 钩子改成 NodeBB 4 的异步写法，不再在加载时打日志
- 一次请求合并查价，接口失败时保留原文，不会把整页打挂
- 已有「时间/价格」记录的代码不会再写一遍
- 读帖时会拆掉旧版插入的 `<font>` 链接，改成统一的行情块
- 声明兼容 `^4.0.0`（旧声明停在 NodeBB 1.18）
